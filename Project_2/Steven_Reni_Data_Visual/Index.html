This is me. A visualization of the genetic data that built me. This tool allows you to view your genome in a new way, giving you the freedom to explore the various parts of genetic code that built you, and in this case, me. When you mouse over you see the rs code (short for Reference SNP ID or rsID) which is a unique identification label assigned to a specific single nucleotide polymorphism (SNP), a variation in a single letter of DNA code (A, T, C, or G) among individual people. When you click a dot it takes you to another page that does a quick google search for any information in regards to that specific gene.

Anything with the lowercase "i" prefix: represents an internal tracking number assigned by 23andMe for specific locations on the genome rather than a standard reference ID. This is most prevalent in the MT (mitochondrial DNA), X, and Y sections and provides little to no information to the user.
