# High Noon

A playable, speculative data self-portrait about living under a dangerous sun.

Open `index.html` in a browser. No build or dependencies are required.

## Controls

- WASD or arrow keys: move
- E: interact with nearby objects
- Click the ground: walk
- Object buttons: interact directly
- Departure slider: preview a different time while inside

Plan supply runs, manage a six-slot inventory, repair your shelter, and watch suit wear, heat, and UV exposure. All UV data and survival rules are fictional.

## Checks

```sh
node --test core.test.js
node --check game.js
```
