00 / DATA STRUCTURES

From individual values to collections

You already know how to store a value, make a decision, repeat instructions, and call a function. Now imagine building a webpage for a student exhibition: each artwork needs a title, a color, and a display status. The exhibition needs a list of artworks.

One value"Night Garden"A title
One object{title: "Night Garden"}A record about an artwork
One array[artwork1, artwork2]A sequence of artworks

By the end: build and edit a collection, retrieve a nested value, loop through records, and explain why two variables can change the same object.

Run each JavaScript block separately in your browser’s developer console. Reload between examples if the console reports that a name has already been declared. The live demos run directly on this page. Expand the gallery’s complete HTML example to make your own file.

01 / DATA STRUCTURES

Arrays: an ordered collection

An array stores a sequence of values. Indexes start at zero; length gives the number of elements.

JavaScript
const palette = ["coral", "teal", "gold"];
console.log(palette[0]);                  // coral
console.log(palette[2]);                  // gold
console.log(palette.length);              // 3
console.log(palette[palette.length - 1]); // gold
console.log(palette[3]);                  // undefined

palette[1] = "navy";
console.log(palette); // ["coral", "navy", "gold"]
Index 0coralFirst element
Index 1tealSecond element
Index 2goldThird element

Predict first: what does palette[1] contain after the assignment? What is the last valid index when the length is 5?

Check your prediction

It contains "navy". A five-element array has indexes 0 through 4.

02 / DATA STRUCTURES

Change and inspect a palette

Methods are functions accessed through a value. push adds at the end; pop removes and returns the last element.

JavaScript
const colors = ["coral", "teal"];
const size = colors.push("gold");
console.log(size);                    // 3 (new length)
const removed = colors.pop();
console.log(removed);                 // gold
console.log(colors.includes("teal")); // true
console.log(colors.indexOf("pink"));  // -1 (not found)
console.log(colors.slice(0, 1));       // ["coral"]
console.log(colors.join(" + "));       // coral + teal
console.log(colors);                  // ["coral", "teal"]

slice(0, 1) leaves the palette intact. To remove an element at a chosen index, use colors.splice(index, 1). Avoid delete colors[index]: it leaves an empty slot.

03 / DATA STRUCTURES
Objects: named information
An object groups named properties. Use dot notation for a fixed name and brackets for a name stored in a variable.
JavaScript
const artwork = {
  title: "Night Garden",
  year: 2026,
  displayed: false,
  "main color": "teal"
};

console.log(artwork.title);         // Night Garden
console.log(artwork["main color"]); // teal
const field = "year";
console.log(artwork[field]);        // 2026
console.log(artwork.field);         // undefined

artwork.displayed = true; // Update
artwork.medium = "print"; // Add
delete artwork.year;     // Remove
console.log(Object.keys(artwork));
// ["title", "displayed", "main color", "medium"]
The punctuation has a job: braces enclose the record, a colon connects a key to its value, and commas separate properties. artwork.field asks for a property literally named field.
04 / DATA STRUCTURES
Combine them: an array of objects
Arrays can contain objects, and object properties can contain arrays. Read a nested expression one step at a time.
JavaScript
const exhibition = [
  {title: "Night Garden", tags: ["print", "nature"], displayed: true},
  {title: "Signal", tags: ["sound", "digital"], displayed: false}
];

console.log(exhibition[0].title);   // Night Garden
console.log(exhibition[1].tags[0]); // sound
exhibition[1].tags.push("interactive");
console.log(exhibition[1].tags.length); // 3
1. exhibition[1]Get the second artwork.
2. .tagsGet that artwork’s tags array.
3. [0]Get its first tag: “sound”.
Check an index before reading deeper. Here, exhibition[2] is undefined; trying exhibition[2].title throws a TypeError.
05 / DATA STRUCTURES
Use functions and loops with records
for...of visits array elements. A function can receive the collection and return a result.
JavaScript
function getDisplayedTitles(works) {
  const titles = [];
  for (const work of works) {
    if (work.displayed) {
      titles.push(work.title);
    }
  }
  return titles;
}

const works = [
  {title: "Night Garden", displayed: true},
  {title: "Signal", displayed: false},
  {title: "Drift", displayed: true}
];
console.log(getDisplayedTitles(works));
// ["Night Garden", "Drift"]
Trace it: the first artwork contributes a title, the second is skipped, and the third contributes a title. The function returns a new array for the caller to use.
JavaScript
const titles = ["Night Garden", "Signal"];
for (let i = 0; i < titles.length; i++) {
  console.log(i + ": " + titles[i]);
}
// 0: Night Garden
// 1: Signal
Use an index loop when you need the position. The condition is i < titles.length; using <= would visit one position beyond the end.
06 / DATA STRUCTURES
const does not freeze an object
Objects are mutable. Assigning an object to another variable shares its identity. A const binding cannot be reassigned, but its object can change.
JavaScript
const original = {title: "Drift", tags: ["ink"]};
const shared = original;
shared.title = "Drift II";
console.log(original.title);      // Drift II
console.log(shared === original); // true
console.log({title: "Drift"} === {title: "Drift"}); // false

const copy = {...original}; // Shallow copy
copy.title = "Study";
copy.tags.push("paper");
console.log(original.title); // Drift II
console.log(original.tags);  // ["ink", "paper"]

// original = {}; // TypeError if uncommented
In this artwork example, spreading creates a new outer record, but both records still use the same tags array. Use {...original, tags: [...original.tags]} to copy that array too. Objects inside a copied array would still be shared.
Functions can edit a shared object
JavaScript
function rename(work, newTitle) {
  work.title = newTitle;
}
const piece = {title: "Untitled"};
rename(piece, "After Rain");
console.log(piece.title); // After Rain
The parameter receives the object reference as its value. Editing work.title reaches the same record as piece.title. Reassigning the parameter itself would only change the local binding.

const artworks = [
  {title: "Night Garden", medium: "Print", displayed: true},
  {title: "Signal", medium: "Sound", displayed: false},
  {title: "Drift", medium: "Drawing", displayed: true}
];
let displayedOnly = false;

function renderGallery() {
  const list = document.querySelector("#gallery");
  list.replaceChildren();
  let visibleCount = 0;

  for (const artwork of artworks) {
    if (!displayedOnly || artwork.displayed) {
      const item = document.createElement("li");
      item.textContent = artwork.title + " — " + artwork.medium;
      list.append(item);
      visibleCount++;
    }
  }
  document.querySelector("#count").textContent =
    visibleCount + " of " + artworks.length + " artworks shown";
  const button = document.querySelector("#toggle");
  button.textContent = displayedOnly ? "Show all artworks" : "Show displayed only";
  button.setAttribute("aria-pressed", String(displayedOnly));
}

document.querySelector("#toggle").addEventListener("click", () => {
  displayedOnly = !displayedOnly;
  renderGallery();
});
renderGallery();
</script>
</body>
</html>

    Practice: make a studio inventory
    Create an array named supplies with three objects. Each needs a name and a numeric quantity.
    1. Print the second supply’s name.
    2. Add another supply with push().
    3. Write a function that returns the total quantity.
    4. Change one quantity and run the function again.
    One possible solution
    JavaScript
    const supplies = [
  {name: "Brushes", quantity: 4},
  {name: "Markers", quantity: 6},
  {name: "Sketchbooks", quantity: 2}
];
console.log(supplies[1].name); // Markers
supplies.push({name: "Erasers", quantity: 3});

function totalQuantity(items) {
  let total = 0;
  for (const item of items) {
    total = total + item.quantity;
  }
  return total;
}
console.log(totalQuantity(supplies)); // 15
supplies[0].quantity = 5;
console.log(totalQuantity(supplies)); // 16
    Explain before you run
    • How do [] and {} help describe an exhibition?
    • Why is supplies[supplies.length] undefined?
    • Does const backup = supplies make an independent copy?
    Check your understanding
    An array holds the sequence of artworks; an object holds one artwork’s named properties. The length is one greater than the last index in this inventory. Assigning supplies shares the array, so edits through backup affect that same array.
