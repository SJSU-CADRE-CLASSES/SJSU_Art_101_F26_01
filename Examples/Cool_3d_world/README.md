# Valley Vista

An interactive Three.js procedural city inspired by the Santa Clara Valley — a compact urban grid nestled between mountain ranges, explored from a bird's-eye view.

## Run

```bash
npm install
npm run dev
```

## Controls

- **Drag** — pan across the valley
- **Right-drag** (or Shift-drag) — rotate / orbit the camera
- **Scroll** — zoom in / out
- **Click markers** or use the waypoint list — learn about points of interest
