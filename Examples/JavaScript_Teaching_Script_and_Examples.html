0:00–2:00

Hook: a webpage works like a campus café

SAY: “What makes a webpage respond when you click a button, submit a form, or add something to a shopping cart?”

HTML is the café building and menu. It provides structure and content.

CSS is the color, furniture, and decoration. It controls appearance.

JavaScript is the staff. It takes information, follows rules, and changes what the customer sees.

ASK: “If the café has a menu but no staff, what can a customer actually do?”
KEY IDEA: JavaScript gives a webpage behavior.
2:00–9:00

Variables: labeled storage containers

SAY: “A variable works like a labeled container behind the café counter. The label tells us what the container holds, and the program can use that label later.”
const studentName = "Maya";
const coffeePrice = 4;
let coffeesRemaining = 10;

coffeesRemaining = coffeesRemaining - 1;

const creates a label whose assigned value should not be replaced. let creates a label whose value may change.

ASK: “What is stored in coffeesRemaining after the last line?” Answer: 9.

Common value types:

const name = "Jordan";       // String: text
const credits = 12;         // Number
const isEnrolled = true;    // Boolean: true or false

Comparisons produce either true or false:

credits >= 12   // true
credits < 12    // false
credits === 12  // true
CLARIFY: One equals sign assigns a value. Three equals signs compare values.
9:00–13:00

If–else statements: the decision maker

SAY: “An if statement works like a bouncer following a rule. If the condition is true, one block runs. Otherwise, the else block runs.”
const hasStudentID = true;

if (hasStudentID === true) {
  console.log("Welcome to the event!");
} else {
  console.log("Please visit the front desk.");
}

else if adds another possibility:

const score = 82;

if (score >= 90) {
  console.log("Excellent!");
} else if (score >= 70) {
  console.log("You passed!");
} else {
  console.log("Keep practicing.");
}
ASK: “What appears for 95? What appears for 65?” Answers: Excellent! and Keep practicing.
KEY IDEA: JavaScript checks the branches from top to bottom and stops at the first true condition.
13:00–17:00

Loops: repeat without rewriting

SAY: “A café worker can place five cups on the counter by repeating one instruction. A loop gives the computer the same kind of repetition rule.”
for (let cup = 1; cup <= 5; cup++) {
  console.log("Place cup " + cup);
}

Read it aloud: “Start cup at 1. Continue while cup is at most 5. Add 1 after each repetition.”

ASK: “What changes if 5 becomes 10?” Answer: the loop runs ten times.
EXPLAIN: cup++ is shorthand for cup = cup + 1.

Connecting JavaScript to HTML

<p id="result">Waiting...</p>

<script>
  document.querySelector("#result").textContent =
    "Time to study!";
</script>

HTML creates the paragraph. JavaScript finds the ID result and changes its text.

17:00–22:00

Follow-along 1: Study Assistant

Create a file named index.html, copy the complete program below, save it, and open it in a browser.

<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Study Assistant</title>
</head>
<body>
  <h1>Study Assistant</h1>
  <p id="result"></p>

  <script>
    const studentName = prompt("What is your name?");
    const studyMinutes = Number(
      prompt("How many minutes can you study today?")
    );

    let advice;

    if (studyMinutes >= 60) {
      advice = "You have time for a focused study session.";
    } else if (studyMinutes >= 25) {
      advice = "Try one Pomodoro study session.";
    } else {
      advice = "Review one small topic. A little progress counts!";
    }

    document.querySelector("#result").textContent =
      "Hi, " + studentName + "! " + advice;
  </script>
</body>
</html>
PREDICT BEFORE RUNNING: What advice appears for 75 minutes, 30 minutes, and 10 minutes?
MODIFY: Change a threshold or rewrite one message.

22:00–27:00

Follow-along 2: Five-Day Practice Plan

Replace the contents of the previous file with this complete program.

<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>JavaScript Practice Plan</title>
</head>
<body>
  <h1>Five-Day JavaScript Practice Plan</h1>
  <ul id="studyPlan"></ul>

  <script>
    let listItems = "";

    for (let day = 1; day <= 5; day++) {
      listItems = listItems +
        "<li>Day " + day +
        ": Practice JavaScript for 15 minutes</li>";
    }

    document.querySelector("#studyPlan").innerHTML = listItems;
  </script>
</body>
</html>
SAY: “The variable begins as empty text. Each repetition adds one list item. After five repetitions, JavaScript places the completed list inside the page.”
TRACE: After the fifth repetition, day becomes 6. Is 6 <= 5 true? No, so the loop stops.
MODIFY: Change 5 to 7, start at 0, or replace day++ with day = day + 2.

    27:00–28:00

    Challenge and recap

    const energy = 6;

if (energy >= 5) {
  for (let task = 1; task <= 3; task++) {
    console.log("Complete task " + task);
  }
} else {
  console.log("Take a short break.");
}
    ASK: Which branch runs? How many times does the loop run? What changes if energy becomes 3?

    Answers: The first branch runs. The loop runs three times. With an energy value of 3, the else branch prints “Take a short break.”

    FINAL MODEL: Variables remember. If–else statements decide. Loops repeat. HTML provides the page. JavaScript makes the page respond.

    Exit ticket
