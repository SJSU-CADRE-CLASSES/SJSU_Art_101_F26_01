Previous knowledge reminder

  • Variables remember values. Use const when you will not reassign a variable, and let when you will.
  • If–else statements decide. A condition evaluates to true or false and selects which block runs.
  • Loops repeat. A for loop has a starting value, a condition, and an update after each repetition.

Functions organize these familiar instructions into reusable tasks. Parameters supply inputs; return values let tasks exchange results.

01 / Function basics

A reusable task with a name

A function groups instructions under a name. Defining the function describes the task. Calling it runs the task.

Think of a café recipe: the same instructions can make another order when you supply different ingredients.

JavaScript · definition and call
function makeGreeting(name) {
  return "Hello, " + name + "!";
}

const message = makeGreeting("Maya");
console.log(message); // Hello, Maya!
PartJob
functionBegins the function declaration.
makeGreetingNames the task.
(name)Names an input the function receives.
{ ... }Contains the instructions.
makeGreeting("Maya")Calls the function with a specific value.

The function runs when the call happens. A definition alone does not print or display anything.

02 / Inputs

Parameters name inputs.
Arguments supply values.

A parameter is the input name in a function definition. An argument is the actual value or expression supplied in a call.

JavaScript · multiple inputs
function calculateSubtotal(price, quantity) {
  return price * quantity;
}

const cupPrice = 4;
const cupsOrdered = 3;

const subtotal = calculateSubtotal(cupPrice, cupsOrdered);
console.log(subtotal); // 12
Argument in the callValueParameter inside the function
cupPrice4price
cupsOrdered3quantity

Values line up by position. The caller's variable name can differ from the parameter's name. A call can also use literal values: calculateSubtotal(4, 3).

You pass the value stored in a variable. You do not move that variable into another function.

03 / Outputs

return sends a result back

return finishes the current function call and supplies its result to the caller. Store that result in a variable or use it in another expression.

JavaScript · a reusable result
function double(number) {
  return number * 2;
}

const firstResult = double(5);
const nextResult = double(firstResult);

console.log(firstResult); // 10
console.log(nextResult);  // 20

Printing and returning do different jobs

JavaScript · the missing return
function printDouble(number) {
  console.log(number * 2);
}

const result = printDouble(5); // Prints 10
console.log(result);          // undefined

console.log() displays information in the developer console. The printDouble() function has no return value expression, so its call evaluates to undefined. To reuse the calculated number, add return number * 2;.

These short JavaScript examples run in a browser's developer console, or inside a <script> element in an HTML file. The complete webpages below display their results directly.

04 / Connected tasks

A café order in three functions

Each function handles one task. The returned subtotal becomes an argument to the discount function. The returned total becomes an argument to the receipt function.

JavaScript · a complete chain
function calculateSubtotal(price, quantity) {
  return price * quantity;
}

function applyDiscount(subtotal, discount) {
  return subtotal - discount;
}

function makeReceipt(customerName, total) {
  return customerName + " owes $" + total.toFixed(2);
}

const subtotal = calculateSubtotal(4, 3);
const total = applyDiscount(subtotal, 2);
const receipt = makeReceipt("Maya", total);

console.log(receipt); // Maya owes $10.00
1. calculateSubtotal(4, 3)return 4 * 312
2. applyDiscount(12, 2)return 12 - 210
3. makeReceipt("Maya", 10)return a receipt string$10.00

toFixed(2) formats the number with two decimal places and returns text. We format the amount at the display step so the earlier calculations keep using numbers.

This simplified order uses nonnegative quantities and a discount no larger than the subtotal. Its dollar amounts illustrate value passing.

05 / Scope

Local names stay in their function

A parameter and a variable declared inside a function belong to that function's local scope. A separate function defined outside it cannot directly read those local variables.

JavaScript · return the local value
function addFee(total) {
  const fee = 2;
  return total + fee;
}

const finalTotal = addFee(10);
console.log(finalTotal); // 12

// console.log(fee);     // ReferenceError if uncommented

Reassigning a number parameter leaves the caller's variable alone

JavaScript · primitive value passing
function addOne(number) {
  number = number + 1;
  return number;
}

let score = 5;
const increased = addOne(score);

console.log(score);     // 5
console.log(increased); // 6

score = addOne(score);
console.log(score);     // 6

The function receives the numeric value 5. Changing its local parameter does not reassign score. The caller changes score only when it assigns the returned value.

This example uses primitive values such as numbers and strings. Objects and arrays add a distinction: their properties or elements can be changed through a shared object reference. That is a separate topic.

Top-level variables can be visible inside functions, but explicit parameters make it easier to see where a function's inputs come from.

07 / Physical computing

A function chain inside a kinetic artwork

The supplied final2.ino sketch controls a pump and valve system. Its applyIntensity() function calls helper functions to keep an intensity value within bounds and convert it into durations.

This small excerpt shows the relationship in Arduino C++. The original applyIntensity() has more instructions after these two lines.

Arduino C++ · excerpt from final2.ino
float clampFloat(float x, float lo, float hi) {
  if (x < lo) return lo;
  if (x > hi) return hi;
  return x;
}

int lerpInt(int slowVal, int fastVal, float t) {
  t = clampFloat(t, 0.0f, 1.0f);
  return slowVal + (int)((fastVal - slowVal) * t);
}

// Inside applyIntensity(float intensity):
intensity = clampFloat(intensity, 0.10f, 1.0f);
beat1PumpTime = lerpInt(1450, 260, intensity);

The same relationship in JavaScript

clampFloat() returns a bounded value. lerpInt() blends between two durations. The coordinating function calculateBeat1PumpTime() returns the result instead of updating the sketch's shared beat1PumpTime variable.

JavaScript · adapted calculation
function clampFloat(x, lo, hi) {
  if (x < lo) return lo;
  if (x > hi) return hi;
  return x;
}

function lerpInt(slowVal, fastVal, t) {
  const boundedT = clampFloat(t, 0, 1);
  return slowVal + Math.trunc((fastVal - slowVal) * boundedT);
}

function calculateBeat1PumpTime(rawIntensity) {
  const intensity = clampFloat(rawIntensity, 0.10, 1);
  return lerpInt(1450, 260, intensity);
}

const pumpTime = calculateBeat1PumpTime(0.5);
console.log(pumpTime); // 855 milliseconds

Clamp means limit a number to a range. Lerp is short for linear interpolation, which blends between endpoints. Math.trunc() removes the fractional part, matching the integer conversion in this excerpt's bounded calculation.

Practice example

Predict the final number, then verify it in your browser console.

JavaScript · values between functions
function addTwo(value) {
  return value + 2;
}

function triple(value) {
  return value * 3;
}

const first = addTwo(4);
const final = triple(first);
console.log(final);
Explanation

addTwo(4) returns 6. The variable first stores 6. Then triple(first) receives 6 and returns 18, which final stores.
